# ビール参考画像（v47）

## 収録範囲

- ブラインド判定・代表ビール購入ガイドの全58スタイル。
- 筆記問題で参照する追加10スタイル：ランビック、ヴァイツェンボック、フェストビア、クリームエール、ヘレスボック、オートミールスタウト、カリフォルニアコモン、アメリカンラガー、ベストビター、アイリッシュ・レッドエール。
- 合計68種類。既存13種類は実物写真、残る55種類はAI生成の参考イラスト。
- 写真の帰属とライセンスは `beer-photos.json`、AI画像は `beer-illustrations.json`、生成プロンプトは `beer-illustration-prompts.json` に記録。

## 表示

学習モードで回答を確認した後と、最終試験・模試の復習で表示します。問題文、解説、選択肢、正答・誤答それぞれの選択肢解説からスタイル名を探し、関連画像を表示します。正答・誤答にかかわらず表示し、重複する同じスタイルの画像は1点にまとめます。

ブラインド判定では正答と誤答候補の画像を結果画面で比較できます。購入ガイドには常時表示します。筆記とブラインド判定の回答前には新しい画像を表示しません。

## 誤認防止

実物写真には銘柄・撮影者・出典・ライセンスを記載します。AI画像にはスタイル名と「AI参考イラスト」「実在銘柄の写真ではありません」を明記し、架空の銘柄・瓶ラベルは使用しません。原本から縦横比を維持してWebPに変換・圧縮し、色や泡の描き替えは行っていません。

スタイル名は長い名称から照合します。例えば「クリスタルヴァイツェン」「ダークヴァイツェン」「ヴァイツェンボック」に、短い「ヴァイツェン」の画像を誤って当てません。まだ画像のない補助名称もこの照合の対象に含めます。

画像は外観の代表例であり、スタイル全体の色域や銘柄ごとの差を表しません。特にランビックは無果実・ストレートの例、ヴァイツェンボックは濃色の例、グレープエールは色域のうち一例です。色・泡・濁りだけでスタイルを断定せず、香味・製法と合わせて学習してください。
