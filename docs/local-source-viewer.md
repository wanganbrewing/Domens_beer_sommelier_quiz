# 資料参照機能の更新

v56で端末PDFの確認ボタン、ファイル選択画面、PDF表示機能を廃止しました。回答後と復習からは、制限付きGoogle Driveの該当箇所画像を開きます。使い方と対応範囲は[Drive画像リンクの仕様](drive-source-images.md)を参照してください。

`source-links.json` の元資料名、SHA-256、ページ番号、問題との対応、矩形は、画像の出典と同一性を確かめるために維持しています。資料の読み込み、共有権限、学習履歴に関する新たな承認や自動削除を設定したものではありません。

`tools/check_source_rendering.mjs` と同梱PDF.jsは、保守担当者が原資料と画像を照合するオフラインQA用として残しています。ブラウザーの学習アプリからは読み込まず、端末PDFの操作や表示には使用しません。
