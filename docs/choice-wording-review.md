# 限定・断定表現の見直し（v51）

## 修正範囲

全1080問と、別セット16組の64選択肢を対象に、露骨な限定・断定表現を点検しました。「だけ」「のみ」「しか」「必ず」「一切」「常に」「唯一」などに加え、「完全に」「無関係」などの候補も確認しています。

- 本体129問の147選択肢を修正。保管中の非出題問題11問を含みます。
- 別セット7組の9選択肢を修正。
- 合計156選択肢。いずれも元の誤答位置を維持し、正答選択肢は変更していません。
- 単語を削るだけでなく、仕組み、分類、香味との対応、図表の単位などの具体的な取り違えへ書き直しました。解説も対応させています。

例：

- 「腐卵臭は必ずヘキサン酸エチルによって生じる」→「腐卵臭の代表的な原因物質は、ヘキサン酸エチルである」。原因物質の取り違えを問います。
- 「液色の黒さのみで決まる」→「黒さが近いビールは、残糖に差があっても同程度のボディになる」。色とボディを混同する具体的な判断を問います。
- 「すべてのビールで法律上必須」→「残った糖をアルコールへ変える」。ろ過と発酵の作用の違いを問います。

## 保持した条件と未完了部分

「専用グラス」「原材料を限定した歴史」「表に載っていることだけでは有効性・安全性は確認できない」など、内容に必要な語は残しています。健康資料の年代、製品差、民間療法としての注意書きも維持しています。

次の8選択肢は、限定語を外すと正答にもなりうる、または別の主張に置き換えるための根拠が不足するため保留しました。全選択肢の改善完了とはしていません。

- A-330：スタイルガイドと法的拘束力の説明、1選択肢。
- B-118：醸造規模と品質課題、2選択肢。
- C-205：キリン前身の資本構成、1選択肢。
- C-228：「ジャパニーズ・ホップ」の対象品種と官能傾向、1選択肢。
- C-239：標準ケグと小型ケグの容量区分、1選択肢。
- C-240：欧州瓶の定番容量の範囲、2選択肢。

v51時点で残した「という説明は資料の内容と一致しない」という機械的な反転表現は、[v52の修正](concrete-distractor-review.md)で具体的な誤った内容へ置き換えました。一部正答の一般化と、上記8選択肢の追加根拠確認は、全体の改善完了とは扱っていません。

## 確認と保護

- 全156案を設問・他の選択肢・既存解説と照合し、独立レビューしました。曖昧な「補える」、共通の分析枠と同じアロマ構成の混同、隣の選択肢との近似の3点を修正しました。
- 根拠は既存教材に紐づく解説と問題間の整合性です。今回、全原資料PDFを再読したものではありません。
- 問題文、ID、正答インデックス、正答数、出典、出題対象、1080問／出題対象1030問は維持しています。
- アプリ処理はv50と同一で、変更は版番号・読込用の版指定だけです。保存済みの出題セットはその回の終了まで保持します。
- 新しい回帰検査は、v50との差分が明示した修正に限られること、正答・出典等の不変、重複なし、繰り返し適用の安定性を確認します。既存の採点・履歴・模試・再挑戦検査も実行します。
- 確認済みの変更は `data/choice-wording-revisions.json` に保持し、教材データの再生成で旧表現へ戻らないようにしています。予期しない元データの変更は検出して停止します。
