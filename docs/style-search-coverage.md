# スタイル検索リンクの表記ゆれ・略称対応

## 確認した不具合

利用者の添付画面を実際に確認したところ、問題 A-328「『酸のあるビール』の出自を3系統に分けると？」の回答後説明で「ゴーゼ」「ランビック」はリンク済みですが、「ベルリナー」「フランダース」はリンクがありませんでした。長い名称を中心に作った語彙に、この略称がなかったことが原因です。問題文や出典の誤りを直す変更ではありません。

## 修正範囲

- 既存カタログだけでなく、筆記1080問と別セット・テイスティング資料の実際の表記も監査しました。
- 明確な97表記を追加しました。「ポーター」「スタウト」「ピルス」「IPA」、中黒付きの「フランダース・レッド」「ベルリナー・ヴァイセ」、筆記に登場する「ロッゲンビア」などです。
- 別に10の曖昧な略称を、確認した前後の表現に限定してリンク化します。たとえば「乳酸菌系（ベルリナー/ゴーゼ）」「樽混合熟成系（フランダース）」は対象、「フランダース地方の郷土料理」は対象外です。
- 添付の2略称は計7問に登場し、説明・選択肢・選択肢別解説を個別フィールドとして数えると計29箇所が新しくリンクになります。選択肢のリンクは回答後の解説・復習にだけ表示し、チェックボックス欄では従来どおり表示しません。
- 全変更を実データに適用すると、189問の回答後表示に差分があり、そのうち168問は検索リンク追加または短いリンクから完全な表示名への置換を含みます。残りは誤リンク抑止です。これは問題の追加・書換件数ではありません。
- 「フランダース」の樽熟成系は、赤系か褐色系かを勝手に決めません。検索語は表示名＋「ビール スタイル」のままです。A-328なら「ベルリナー ビール スタイル」「フランダース ビール スタイル」になります。

## 誤リンクを避ける境界

- カタカナ語の一部を取り出しません。「カラピルス」「ラオホマルツ」「ダブルチーズ」「トリプルアクセル」などは対象外です。
- 麦芽・酵母・用具の修飾語をスタイルとして扱いません。例：「ピルスナー麦芽」「ヴァイツェン酵母」「ヴァイツェングラス」。
- 確認した銘柄の一部分はリンクにしません。例：「ピルスナーウルケル」「セゾン・デュポン」「ウェストマール ダブル」「フリュー ケルシュ」。
- 「オルヴァル」は銘柄なので文章の自動リンクから外します。ただし既存カタログが明示的にスタイル欄に使っている表示は、その欄全体のリンクを維持します。
- 既存テキストでリンクが減る全箇所を比較し、銘柄・原料・酵母の除外、または完全な表示名への置換によるものと確認しました。
- 一般的な「エール」「ラガー」、色や味の「マイルド」「ブラウン」などを一律にリンクにはしていません。未確認の略称・表記を完全網羅するという主張ではありません。

- 問題・正答・採点・選択肢順・保存履歴・出典・Drive参照・画像・アクセス照合値は変更していません。アプリ本体の表示呼び出し箇所も変更していません。
