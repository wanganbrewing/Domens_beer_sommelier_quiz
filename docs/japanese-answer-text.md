# 英語選択肢・解答の日本語併記

基本1080問と別セット16組の選択肢、選択肢別解説、全体解説を確認しました。英語のまま意味を読み取りにくい箇所を中心に250フィールドへ日本語を加えています。

- 選択肢42件（基本40件、別セット2件）
- 選択肢別解説185件、全体解説23件
- 基本47問と別セット16組。問題IDのまとまりでは54問です。

化合物名、カスク部品名、評価語、健康資料の図表の語句などを併記しました。正解表示・復習は実際に出題した選択肢を参照するため、同じ日本語も表示されます。

英語の意味自体を問うmetallic・vegetalは、選択肢では日本語の読みを加え、意味は解答後の説明で確認できます。µg/bottleの意味を問う問題では、回答前に意味を追加すると正答の手がかりになるため単位表記を維持し、回答後の日本語説明を使います。IPA、ABV、一般的な単位・固有名、すでに日本語訳がある語句は一律に訳し直していません。

250案を独立して照合し、Shiveの読みをシャイヴへ訂正、重複する日本語を3箇所整理しました。正誤、否定、条件、数値、正答数、4択、ID、出典は維持しています。B-181の「微生物の住処（continuity）」は元の語と説明の対応が曖昧なままですが、今回の訳はcontinuity＝継続性にとどめ、根拠なく別の主張へ変更していません。

`data/japanese-answer-text.json` に変更前後を記録しています。生成処理では確認済みの文言修正後に日本語を追加し、再生成・再適用でも重複しません。予期しない元文の変更があれば停止します。保存済みの途中の回は出題時点の表現を保持し、新しく始める回から反映します。
