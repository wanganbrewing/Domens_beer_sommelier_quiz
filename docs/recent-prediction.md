# 直近予想問題集（v71）

2026年11月19日に共有された講義スライド「筆記テストの準備」を選定の最優先根拠とした、50問の独立した学習モードです。公式問題・本番出題の確定情報ではありません。スライドの画像そのものは収録していません。

- 必須・定義7問、ビアスタイル12問、製造・工程17問、サービス・知識14問。
- 最初の7問は純粋令（1516年を含む）と定義を固定順で確認します。他の43問は3章の順序を保ち、章内を毎回シャッフルします。全50問を必ず含め、通常学習の頻度・履歴フィルターで必須項目を落としません。
- 選択肢順は従来どおりランダムです。対象のペアリング問題は既存の検証済み別セットも維持します。
- 時間制限なし、毎問解説、学習履歴・直近正答率は通常学習と共通です。同じIDの採点基準・正答番号は変えず、全50問に解答後の説明があります。完走後は復習、再挑戦、終了を選べます。一般問題の「次の50問」へは混入しません。
- 模試とは別の内容優先セットです。正答数1〜4個の均等配分を適用せず、正答数も回答前には表示しません。
- 通常の頻度別学習、全範囲の40分模試、既存セッション、認証設定、教材の共有権限は変更しません。予想問題集の途中終了・完走結果は再読み込み後も復元します。一般学習の従来の復元規則は維持します。

## 原問題の保護と補足

`questions.json`（1170問、出題対象942問）は v70 と完全に同一です。予想問題集は既存の50 IDを使い、開始時に生成するローカル保存用コピーにだけ、次の補正・補足を適用します。新問題の自動生成はしません。

- A-185：1516年条文に酵母の記載がないことと、発酵に酵母が関わらなかったという意味を区別。
- C-231：IBUをイソα酸の厳密な濃度と同一視しない説明。
- A-073：前駆体SMMの熱分解で生じるDMSと、DMSの揮散を区別。
- ST26-009/010：度数の高低を典型的な比較とし、一律の数値境界にしない。
- ST26-011：Vollbierの原麦汁エキス区分とABVを区別。
- A-066/068/077：標準的工程・通常の糖化温度域・伝統的貯酒という適用範囲を明確化。
- A-214：鼻をつまんでも基本味・口当たり等は残ることを明確化。
- A-262：長期熟成の適性は製品や保存条件によることを補足。
- DS26-011：ライン長さ・内径と圧力損失の説明を直接対応させる。

根拠：既存各問の教材名・ページ・解説に加え、[ドイツ醸造協会の1516年条文](https://brauer-bund.de/reinheitsgebot/entstehung/wortlaut/)、[ASBCの苦味分析法](https://www.asbcnet.org/methods/beer-methods/beer-23-master-method)、[BJCPのDMS説明](https://www.bjcp.org/exam-certification/program/studying/beer-exam-study-guide/troubleshooting/)を照合しました。50問の全選択肢と正答・個別説明をレビューしましたが、全原教材を今回再取得して全ページ再監査したものではありません。

講義画像の細目と各問の対応は `data/recent-prediction-coverage.json` にあります。ドラフトの長さ・内径・高さ・ガス圧・温度も個別に含み、分類では色と発酵形式を区別します。既存のDrive本文リンクは対象3問とその別セットで維持します。50問すべてに本文画像リンクがあるわけではありません。
