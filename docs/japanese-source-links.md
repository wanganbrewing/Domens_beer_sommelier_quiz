# 日本語本文の参照範囲

## 対応済みの範囲

英語講義由来の80問と別セット16組に、原資料の日本語本文を確認して追加しました。元の445参照のうち320参照は該当する日本語も確認、39参照は部分的な訳、86参照は該当箇所の日本語なし・未発見です。これは教材全体の翻訳率ではありません。英国資料の引用8ページは英語のみで、他ページの全画像から日本語訳を探し終えたものではありません。

- 同じページでは英語枠を保持して日本語範囲を加えます。
- 別ページの日本語が確認できた3件は、そのページへ直接進む参照を追加しました。
- OF26-013の乳酸とクローブの取り違えは、日本語の乳酸の酸味と日英のクローブ／4-VGの2箇所で確認し、これまで未対応だった選択肢にも参照を付けました。
- 日本語の一部省略、条件の違い、意訳を完全な対訳と表示しません。部分訳は英語原文と併読してください。

例として、塩・酸について英語がOR、日本語の別ページがANDとなる箇所、英語の連想を日本語では関係性と記す箇所、赤リンゴとアニスのうち日本語は赤リンゴのみの箇所を区別しています。日本語本文のないページへ独自翻訳を原文のように加えていません。

## 日本語主体の教材からの初回追加

新しい問題は作らず、既存4問の9選択肢にだけ追加参照を付けました。

- A-257：品質管理資料p24。定期洗浄の要否。バイオフィルム、ビアストーン、記録管理までこの箇所で確認したものではありません。
- A-258：同資料p13。樽の開栓後の早期使用、移動後の静置、冷蔵保管。ボトル向けの紫外線注意を樽の根拠に流用しません。
- A-261：同資料p13。冷蔵管理、温度変動の回避、ボトルの日光回避。樽生限定の説明をボトルの根拠に流用しません。
- B-283：健康資料p67。プリン体含量に幅がある図の例。糖質、体質、総摂取量、飲酒の健康効果はこの参照の対象外です。古い図表を現行全商品の値として一般化しません。

この4問の残り7選択肢は根拠未確認のため参照リンクを付けません。マーケティング、料理、メニュープランニングなど日本語教材全体の対応は未完です。原資料にない内容を語句の類似だけで結び付けません。

全体で84問＋別セット16組、400選択肢中393選択肢、459参照、273画像単位です。問題・正答・採点・履歴は変更していません。

## 画像と共有

本文や図表の意味を切り落とさないよう周囲を残し、必要なページは全体を保持します。細かい二言語本文や表はスマートフォンで拡大が必要です。画像は一般公開リポジトリへ含めません。Drive閲覧リンクの実反映、受講者権限、端末での確認は別工程です。
