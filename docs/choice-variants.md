# 別セットで再挑戦（v50）

## 対応範囲と使い方

v49（83d5cc17）を基準に、レビュー済みの8問を通常の学習・模試へ統合しました。8問以外への展開は今回の範囲に含みません。

ホームの「対応する8問を学ぶ」からまとめて練習できます。通常の学習・模試でも対象8問が選ばれた場合は同じ仕組みを使用します。対象外の問題は元の選択肢です。再挑戦は問題一覧のやり直し、または結果画面の「同じ問題でもう一度」から行えます。

## 問題の範囲と品質

- 対象：BP26-002、004、006、007、009、013、015、018。
- 各問に元セット＋追加2セット、計24セット。追加は16セット・64記述です。
- 出典：既存教材「0830ビアペアリング2026.pdf」の英語本文・図表。該当ページは3、4、5、7、8、9、12、16、17、19。各セットにページ・出典状態・個別解説を付けています。
- 64記述を教材と照合し、別途レビューしました。講義上の相互作用・推奨例として出題し、すべての人に同じ官能結果が出るとは断定しません。
- 選択肢は毎回4個、正答数は元問題と同じです。問題文は維持し、内容と正誤は事前に確認したセットから選びます。実行時の自動生成や正誤反転は行いません。
- 既存 questions.json、問題ID、問題数、画像は変更しません。

## 保存・採点・互換性

- `choice-variants.js` がデータ形式・重複・正答数を検証し、直前と同じセットを除外します。3回目以降に過去のセットが再登場することはあります。
- 開始時に出題セットを保存します。途中の再読み込みでは並び順・選択内容・解説・正答を保持し、元データが変わってもその回の採点基準は変えません。
- 再挑戦時は同じ問題IDで別セットを選び、回答を消去して開始時刻を更新します。
- 既存の問題単位の履歴・習得判定を維持し、セット別の回答回数・正解回数を追加で保存します。履歴リセット時はセット履歴も消去します。
- 旧形式の進行中セッションはそのまま復旧し、再挑戦時から新方式を使います。別セットの読込失敗時は元の選択肢で学習できます。
- 問題ごとの正答数が変わらないため、模試50問の正答数1～4個を各12～13問とする配分を維持します。
