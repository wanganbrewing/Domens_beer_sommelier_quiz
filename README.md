# BierKompass

**Doemens Biersommelier 試験対策**のための、非公式Web問題集です。指定資料を根拠に独自作成した重複のない全685問を、出題予想頻度・分野・学習履歴で絞り込んで学習できます。

- 公開ページ: https://wanganbrewing.github.io/Domens_beer_sommelier_quiz/
- リポジトリ: https://github.com/wanganbrewing/Domens_beer_sommelier_quiz

> 本アプリは非公式の予想問題集です。Doemens公式問題の転載・再現ではなく、Doemensによる承認・監修を受けたものでもありません。

## 主な機能

- 重複のない685問、7分野
- 3段階の出題予想頻度
  - A: 最頻出予想 272問
  - B: 頻出予想 253問
  - C: 補強・周辺知識 160問
- 頻度を単独または組み合わせて出題
- 50問・40分の「最終試験」コーナー
- 全685問を複数選択式（チェックボックス）に統一
- 正答数は0・1・複数（最大3個）で、回答前には正答数を表示しない
- 最終試験50問のうち35問（70%）は正答が2個以上
- ①②のように複数の問いを結合せず、各問題を一つの論点で構成
- 設問はすべて「正しいものを選ぶ」肯定形
- 最終試験は、選択した分野からほぼ均等に抽出し、基礎的で短い設問を優先する「広く浅く」の構成
- 断片的な穴埋めや、資料を見なければ意味が通じない設問を廃止
- 添付スタイル手帳の52スタイルについて、詳細説明・特徴定義・原材料／工程のいずれか1種類を選ぶ問題を収録
- 既存問題集とは別に、外観→発酵系統→国→原材料・工程→スタイルの順に絞り込む「4ステップ ビアスタイル判定」を収録
- 4ステップ判定の最終候補は、途中で選んだ条件に該当するスタイルを省略せずすべて表示
- 初回アクセス時の簡易パスワード画面（解除状態はブラウザーに保存）
- 検索エンジンへの登録を拒否する `noindex` と `robots.txt`
- 1回50問の学習モード（全問／未回答／過去に不正解／正解済みを除外）
- 問題順・選択肢順のランダム化
- 回答後の正答、解説、選択肢別理由、出典表示
- 問題文の条件に当てはまる正しい選択肢を選ぶ共通案内
- 分野別成績、回答一覧、学習履歴
- ブラウザー再読み込み時の試験状態復元
- パソコン・スマートフォン対応

## 試験形式と採点

公開済みの旧試験規則 `Diplom_Biersommelier_Exam_Regulations_Japanese_2020.pdf` を参考に、Webで再現可能な筆記部分を次のように実装しています。

- 1回約50問、制限時間約40分
- 操作方式は全問チェックボックス式で、正答数0・1・複数の問題を出題
- 選択した各分野から、問題数がほぼ均等になるように出題
- 正しい選択肢1つにつき1点
- 誤った選択肢1つにつき1点減点
- 1問の最低得点は0点
- 正答0個の問題は、「正しい選択肢はない（0個）として回答」で確定した場合に1点
- 獲得点 ÷ 各問題の満点合計が50%以上で合格

官能試験・口頭試験はブラウザー上の選択式問題では再現していません。現行資料に明確な変更がある場合は現行資料を優先してください。

## 分野別問題数

| 分野 | 問題数 |
|---|---:|
| 原材料 | 90 |
| 醸造工程 | 53 |
| 発酵・熟成 | 20 |
| ビアスタイル | 338 |
| ビールの歴史・文化 | 64 |
| 官能評価 | 99 |
| オフフレーバー | 21 |
| **合計** | **685** |

分野ごとの配分は、参照資料から抽出できた独立した根拠箇所の量に応じています。

## 学習履歴とリセット

学習履歴と進行中の回答はブラウザーのローカルストレージに保存されます。外部サーバーには送信されません。

- **選択をクリア**: 現在の問題だけ選択解除
- **今回の試験を最初から**: 同じ問題構成の回答を消して1問目から再開
- **履歴をリセット**: 回答回数、正解数、不正解数、最終回答日時、正解済み状態を確認後に全削除

## 問題データ

`questions.json` の各問題には次の情報があります。

- 固有ID
- 分野、出題予想頻度、複数選択形式
- 問題文、選択肢、正答インデックス
- 全体解説、選択肢ごとの正誤理由
- 出典ファイル名、PDFビューアー上のページまたはスライド番号、見出し・根拠要約

PDF本文の印刷ページ番号を確実に取得できなかった資料は、「PDFビューアー上のページ」と明記しています。

別コーナーの `style-quiz.json` には、52スタイルの発酵系統、国、外観、特徴定義、原材料・工程、出典ページを登録しています。アルコール度数の問題はこの別コーナーへ移さず、既存の `questions.json` 内で「高い（7.0〜15.0%程度）」「中くらい（4.0〜6.9%程度）」「低い（0.0〜3.9%程度）」の3区分から答える形式にしています。

## 起動方法

静的サイトなのでビルドは不要です。ローカルWebサーバーの公開ディレクトリをこのフォルダーに設定し、`index.html` を開きます。`file://` では問題データを取得できないブラウザーがあるため、HTTPサーバー経由で利用してください。

## 構成

- `index.html`: 画面構造
- `styles.css`: レスポンシブデザイン
- `app.js`: 出題、採点、履歴、リセット、復元
- `questions.json`: 全685問と出典情報
- `style-quiz.js`: 4ステップ ビアスタイル判定の進行と判定
- `style-quiz.json`: 52スタイルの判定用データ
- `tests/validate_questions.py`: 問題データの整合性検査

## 注意事項

- 出題予想頻度は資料量、講座での基礎性、複数分野への関連性を基にした非公式の目安です。
- 問題文は、それ自体で解答条件が分かるように整え、「資料の記述と一致するもの」のような出典依存の問い方を使用していません。
- ビアスタイル問題は対象スタイル名を明記し、別分野の語だけで消去できる選択肢を避けています。
- 添付スタイル手帳由来の52問は、1問内の選択肢を「詳細説明」「特徴定義」「原材料・工程」のいずれか1種類に統一しています。近縁スタイルの微差を当てる形式にはしていません。
- 「理解確認：」の有無や選択肢順だけが異なる実質重複313問を削除し、同じ内容は1問だけ残しています。
- 情報源そのものを暗記させる2問は削除しました。各問題の根拠となる出典表示は回答後に引き続き確認できます。
- Doemensによる本試験を想定し、日本の酒税法・国内団体・国内統計・日本固有のビール史は出題対象から除外しています。
- 断片的だった問題は、1問1テーマで意味が通る理解確認問題へ再構成しています。
- 1問内に①②の別問題を並べる形式は廃止し、全問を単一テーマに統一しています。
- 人物問題はパスツール、ハンセン、リンデ、グロル、ギネス、ドレーアー、ゼードルマイヤー、ヤコブセン、セリスなど、醸造史上の代表的人物に限定し、回答後に人物名と業績を同じ行で確認できます。
- 数値問題は同じ単位を使い、広い差を付ける場合も設問条件の中であり得る値に揃えています。
- 数値の差は広く取る場合がありますが、未来の歴史年や100%を超える割合など、条件上あり得ない値は使用しません。
- アルコール度数問題は既存問題集内に残し、細かな数値の暗記ではなく「高い・中くらい・低い」の3区分で学べる形式にしています。回答後の解説では、根拠資料にある実際の範囲も確認できます。
- 国別の一人当たりビール消費量、水の硬度だけを問う設問、極端な低値・高値を除くIBU/EBC問題は、C「補強・周辺知識」に分類しています。
- 問題文と選択肢に同じ香りや数値の説明を併記し、正答が推測できる表現は削除しています。
- OG・FG（初期比重・最終比重）の数値暗記問題は収録せず、スタイルの原料・外観・風味などを広く学べる問題へ置き換えています。
- 「広く浅く」の範囲を保ちながら、50問分を原材料寄りの設問から醸造工程・発酵の理解確認へ振り向けています。
- 資料間に矛盾があると判断した記述は自動的に採用せず、確認可能な記述を優先しています。
- 元資料の改訂により、内容や試験形式が変わる可能性があります。
- 初回アクセス画面は静的サイト上の簡易的な閲覧制限です。問題データを機密情報として保護する認証機能ではありません。
- 検索除外指定は検索エンジンへの要請であり、PublicリポジトリやURLを完全に非公開にする機能ではありません。
