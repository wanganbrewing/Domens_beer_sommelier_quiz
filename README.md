# BierKompass 1000

**Doemens Biersommelier試験対策**のための非公式Web問題集です。指定された統合版Markdownから、重複のない本編1000問を取り込み、出題予想頻度・分野・学習履歴で絞り込んで学習できます。

- 公開ページ: https://wanganbrewing.github.io/Domens_beer_sommelier_quiz/
- リポジトリ: https://github.com/wanganbrewing/Domens_beer_sommelier_quiz

> 本アプリは非公式の予想問題集です。Doemens公式問題の転載・再現ではなく、Doemensによる承認・監修を受けたものでもありません。

## 今回の問題データ

設問、選択肢、正答、解説は `ドゥーメンス予想問題1000問_完全統合版.md` の本編1000問へ差し替えています。Markdown末尾の模擬試験50問は本編問題の再掲であるため、問題バンクには重複登録していません。最終試験では本編1000問から毎回50問を抽出します。

- A「最頻出予想」: 400問（A 340問＋スタイル集中 S 60問）
- B「頻出予想」: 350問
- C「補強・周辺知識」: 250問
- 全問4選択肢の複数選択式
- 正答数は1〜4個（回答前には表示しません）
- 問題ID、問題文とも重複なし

## 主な機能

- 1回50問の学習モード（全問／未回答／過去に不正解／正解済みを除外）
- 50問・40分の最終試験
- 頻度と分野を単独または組み合わせて出題
- 問題順・選択肢順のランダム化
- 回答後の正答、解説、選択肢別理由、出典表示
- 分野別成績、回答一覧、永続する学習履歴
- 再読み込み時の回答状態復元と各種リセット
- パソコン・スマートフォン対応
- 外観、発酵系統、国、原材料・工程から絞り込む「4ステップ ビアスタイル判定」
- 統合版Markdownのスタイル判定モジュール60問を抽出し、直接判定25問を4ステップ判定の手掛かり・除外ポイントへ連携
- 初回アクセス時の簡易パスワード画面
- 検索エンジンへの登録を拒否する `noindex` と `robots.txt`

## 試験形式と採点

公開済みの旧試験規則 `Diplom_Biersommelier_Exam_Regulations_Japanese_2020.pdf` を参考に、Webで再現可能な筆記部分を次のように実装しています。

- 1回50問、制限時間40分
- 全問チェックボックス式で、正答は1〜4個
- 正しい選択肢1つにつき1点
- 誤った選択肢1つにつき1点減点
- 1問の最低得点は0点
- 獲得点 ÷ 各問題の満点合計が50%以上で合格
- 最終試験50問のうち35問は正答が2個以上

官能試験・口頭試験はブラウザー上の選択式問題では再現していません。

## 学習履歴とリセット

学習履歴と進行中の回答はブラウザーのローカルストレージに保存され、外部サーバーには送信されません。今回の全問差し替えでは問題ID体系が変わったため、旧版の履歴と進行中試験は引き継がず、新しい問題バンク用に保存領域を更新しています。

- **選択をクリア**: 現在の問題だけ選択解除
- **今回の試験を最初から**: 同じ問題構成の回答を消して1問目から再開
- **履歴をリセット**: 回答回数、正解数、不正解数、最終回答日時、正解済み状態を確認後に全削除

## 問題データ

`questions.json` の各問題には、固有ID、分野、予想頻度、問題文、4つの選択肢、正答インデックス、全体解説、選択肢別理由、元Markdownのファイル名・問題ID・章を登録しています。添付に個別解説がない問題は、その旨を明記しています。

答えの個数は次の内訳です。

| 正答数 | 問題数 |
|---|---:|
| 1個 | 271 |
| 2個 | 8 |
| 3個 | 675 |
| 4個 | 46 |

別コーナーの `style-quiz.json` には52スタイルの発酵系統、国、外観、特徴定義、原材料・工程、出典ページを登録しています。さらに統合版MarkdownからS-001〜S-060を抽出し、「描写から判定」25問、「消去推論」10問、「スタイル比較」15問、「横断特徴」10問として保存しています。直接判定25問は該当スタイルへ関連付け、Step 1の判定描写と回答後の他候補除外ポイントに使用します。

## 起動方法

静的サイトなのでビルドは不要です。ローカルWebサーバーの公開ディレクトリをこのフォルダーに設定し、`index.html` を開きます。`file://` では問題データを取得できないブラウザーがあるため、HTTPサーバー経由で利用してください。

## 構成

- `index.html`: 画面構造
- `styles.css`: レスポンシブデザイン
- `app.js`: 出題、採点、履歴、リセット、復元
- `questions.json`: 全1000問と出典情報
- `style-quiz.js` / `style-quiz.json`: 4ステップ ビアスタイル判定
- `tools/import_integrated_markdown.py`: 指定Markdownの本編1000問を検証・変換する処理
- `tools/import_style_module.py`: S-001〜S-060を抽出し、4ステップ判定へ関連付ける処理
- `tests/validate_questions.py`: 問題データと画面設定の整合性検査

## 注意事項

- 取り込み元Markdownは公開可否が未確認のため、リポジトリへ収録していません。
- 問題データには、取り込み元に含まれる日本固有の話題、比重、サービス、ペアリング等もそのまま含まれます。
- 元Markdownの解説や出典情報が簡略な問題では、アプリ側にもその範囲の情報だけを表示します。
- 初回アクセス画面は静的サイト上の簡易的な閲覧制限であり、問題データを機密情報として保護する認証機能ではありません。
- 検索除外指定は検索エンジンへの要請であり、PublicリポジトリやURLを完全に非公開にする機能ではありません。
