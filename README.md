# BierKompass 1000

**Doemens Biersommelier試験対策**のための非公式Web問題集です。指定された統合版Markdownから本編1000問を取り込み、ペアリング50問を除く950問を、出題予想頻度・分野・学習履歴で絞り込んで学習できます。別コーナーでは、58シナリオのブラインドテイスティング判定を日本語で段階的に練習できます。

- 公開ページ: https://wanganbrewing.github.io/Domens_beer_sommelier_quiz/
- リポジトリ: https://github.com/wanganbrewing/Domens_beer_sommelier_quiz

> 本アプリは非公式の予想問題集です。Doemens公式問題の転載・再現ではなく、Doemensによる承認・監修を受けたものでもありません。

## 今回の問題データ

設問、選択肢、正答、解説は `0901 v3 ドゥーメンス予想問題1000問_完全統合版_v3_25パーセント配分.md` の本編1000問へ差し替えています。Markdown末尾の模擬試験50問は本編問題の再掲であるため、問題バンクには重複登録していません。フードペアリング50問はデータに保持しますが出題対象から外し、最終試験では残る950問から毎回50問を抽出します。

- A「最頻出予想」: 400問（A 340問＋スタイル集中 S 60問）
- B「頻出予想」: 350問
- C「補強・周辺知識」: 250問
- 全問4選択肢の複数選択式
- 正答数は1〜4個（回答前には表示しません）
- 元データの「○つ選べ」という正答数の手掛かりを削除
- 逆問題として取り込まれていた143問を、自然な肯定形の複数選択問題へ修正
- 問題IDと「問題文＋選択肢」の組み合わせは重複なし
- 数値・泡・代表銘柄など異なる知識軸を問う30グループでは、同じ導入文を使いながら選択肢を変えています

## 主な機能

- 1回50問の学習モード（全問／未回答／過去に不正解／正解済みを除外）
- 50問・40分の最終試験
- 頻度と分野を単独または組み合わせて出題
- 問題順・選択肢順のランダム化
- 正答4個の問題が連続しないよう、抽出後に正答数の並びを分散
- 回答後の正答、解説、選択肢別理由、出典表示
- 全問題の正答選択肢に解説を付与し、ビアスタイル395問では誤答選択肢にも識別に役立つ解説を付与
- 回答後の正答・誤答解説にあるスタイル名から、BJCP 2021公式スタイル解説を別タブで参照可能（回答前の選択肢はリンク化しません）
- 分野別成績、回答一覧、永続する学習履歴
- 再読み込み時の回答状態復元と各種リセット
- パソコン・スマートフォン対応
- 外観・香り・味・口当たりから原因とスタイルを推理する「ブラインドテイスティング判定」
- 「観察（回答なし）→原材料・工程→発酵系統→国・地域→候補絞り込み→最終判定→決め手」の7段階
- 判定結果の最後に、各スタイルの代表的なビール銘柄を表示
- 判定後に「このスタイルはこれで覚える」と類似候補との差を表示
- 練習・10問試験・候補絞り込みの弱点モード、各シナリオ10点採点
- 初回アクセス時の簡易パスワード画面
- 検索エンジンへの登録を拒否する `noindex` と `robots.txt`

## 試験形式と採点

公開済みの旧試験規則 `Diplom_Biersommelier_Exam_Regulations_Japanese_2020.pdf` を参考に、Webで再現可能な筆記部分を次のように実装しています。

- 1回50問、制限時間40分
- 全問チェックボックス式で、正答は1〜4個
- 正しい選択肢1つにつき1点
- 誤った選択肢1つにつき1点減点
- 1問の最低得点は0点
- 獲得点 ÷ 各問題の満点合計が50%以上で合格
- 最終試験50問のうち35問は正答が2個以上

官能試験そのものは再現できませんが、添付仕様に基づくブラインドテイスティングの分析手順を選択式で練習できます。口頭試験は再現していません。

## 学習履歴とリセット

学習履歴と進行中の回答はブラウザーのローカルストレージに保存され、外部サーバーには送信されません。今回の差し替えでは正答パターンと設問内容が変わったため、旧版の履歴と進行中試験は引き継がず、新しい問題バンク用に保存領域を更新しています。

- **選択をクリア**: 現在の問題だけ選択解除
- **今回の試験を最初から**: 同じ問題構成の回答を消して1問目から再開
- **履歴をリセット**: 回答回数、正解数、不正解数、最終回答日時、正解済み状態を確認後に全削除

## 問題データ

`questions.json` の各問題には、固有ID、分野、予想頻度、問題文、4つの選択肢、正答インデックス、全体解説、選択肢別理由、出題対象フラグ、元Markdownのファイル名・問題ID・章を登録しています。正答側の解説がない箇所は資料内の正答と分野に基づく学習要点を補い、ビアスタイル分野の誤答には識別軸となる説明を補っています。「AとBのみ」「A〜Cすべて」など他の選択肢番号を参照する回答は使わず、各選択肢を単独で理解できる文章にしています。APAは略記せず「アメリカンペールエール」と表記します。

日本語表現を全1000問で点検し、メモ書き調・直訳調の表現、末尾がコロンだけの設問、正答数を明かす文言を修正しました。回答後に表示されるスタイル名だけを外部リンク化しているため、回答前に正答を推測する手掛かりにはなりません。

答えの個数は次の内訳です。

| 正答数 | 問題数 |
|---|---:|
| 1個 | 133 |
| 2個 | 211 |
| 3個 | 420 |
| 4個 | 236 |

別コーナーの `blind-tasting.json` には、`ブラインドテイスティング判定シミュレーション_完全仕様.md` に含まれる実データ58件を登録しています。仕様本文の「全50シナリオ」という記載と実際の連番数が異なるため、欠落を避けて58件すべてを採用しています。

## 起動方法

静的サイトなのでビルドは不要です。ローカルWebサーバーの公開ディレクトリをこのフォルダーに設定し、`index.html` を開きます。`file://` では問題データを取得できないブラウザーがあるため、HTTPサーバー経由で利用してください。

## 構成

- `index.html`: 画面構造
- `styles.css`: レスポンシブデザイン
- `app.js`: 出題、採点、履歴、リセット、復元
- `questions.json`: 全1000問と出典情報
- `blind-quiz.js` / `blind-tasting.json`: ブラインドテイスティング判定
- `style-links.js`: 回答後に表示するスタイル名とBJCP 2021公式解説の対応表
- `tools/import_integrated_markdown.py`: 指定Markdownの本編1000問を検証・変換する処理
- `tools/build_blind_tasting.py`: 判定仕様Markdownの58シナリオを検証・変換する処理
- `tests/validate_questions.py`: 問題データと画面設定の整合性検査

## 注意事項

- 取り込み元Markdownは公開可否が未確認のため、リポジトリへ収録していません。
- 問題データには取り込み元の全1000問を保持しますが、ペアリング分野はアプリの出題から除外しています。
- 補完解説は試験対策用の要約であり、元資料の文章を転載したものではありません。
- 初回アクセス画面は静的サイト上の簡易的な閲覧制限であり、問題データを機密情報として保護する認証機能ではありません。
- 検索除外指定は検索エンジンへの要請であり、PublicリポジトリやURLを完全に非公開にする機能ではありません。
