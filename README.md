# BierKompass 1000

**Doemens Biersommelier 試験対策**のための、非公式Web問題集です。指定資料を根拠に独自作成した全1,000問を、出題予想頻度・分野・学習履歴で絞り込んで学習できます。

- 公開ページ: https://wanganbrewing.github.io/Domens_beer_sommelier_quiz/
- リポジトリ: https://github.com/wanganbrewing/Domens_beer_sommelier_quiz

> 本アプリは非公式の予想問題集です。Doemens公式問題の転載・再現ではなく、Doemensによる承認・監修を受けたものでもありません。

## 主な機能

- 1,000問、12分野
- 3段階の出題予想頻度
  - A: 最頻出予想 350問
  - B: 頻出予想 400問
  - C: 補強・周辺知識 250問
- 頻度を単独または組み合わせて出題
- 50問・40分の「最終試験」コーナー
- 全1,000問を複数選択式（チェックボックス）に統一
- 正答数は0・1・複数（最大3個）で、回答前には正答数を表示しない
- 最終試験は、選択した分野からほぼ均等に抽出し、基礎的で短い設問を優先する「広く浅く」の構成
- 断片的な穴埋めや、資料を見なければ意味が通じない設問を廃止
- 初回アクセス時の簡易パスワード画面（解除状態はブラウザーに保存）
- 学習モード（全問／未回答／過去に不正解／正解済みを除外）
- 問題順・選択肢順のランダム化
- 回答後の正答、解説、選択肢別理由、出典表示
- 分野別成績、回答一覧、学習履歴
- ブラウザー再読み込み時の試験状態復元
- パソコン・スマートフォン対応

## 試験形式と採点

公開済みの旧試験規則 `Diplom_Biersommelier_Exam_Regulations_Japanese_2020.pdf` を参考に、Webで再現可能な筆記部分を次のように実装しています。

- 1回約50問、制限時間約40分
- 操作方式は全問チェックボックス式で、正答数0・1・複数の問題を出題
- 選択した各分野から、問題数がほぼ均等になるように出題
- 正しい選択肢1つにつき1点
- 誤った選択肢1つにつき1点減点
- 1問の最低得点は0点
- 正答なしの問題は、何も選択せず回答を確定した場合に1点
- 獲得点 ÷ 各問題の満点合計が50%以上で合格

官能試験・口頭試験はブラウザー上の選択式問題では再現していません。現行資料に明確な変更がある場合は現行資料を優先してください。

## 学習履歴とリセット

学習履歴と進行中の回答はブラウザーのローカルストレージに保存されます。外部サーバーには送信されません。

- **選択をクリア**: 現在の問題だけ選択解除
- **今回の試験を最初から**: 同じ問題構成の回答を消して1問目から再開
- **履歴をリセット**: 回答回数、正解数、不正解数、最終回答日時、正解済み状態を確認後に全削除

## 問題データ

`questions.json` の各問題には次の情報があります。

- 固有ID
- 分野、出題予想頻度、複数選択形式
- 問題文、選択肢、正答インデックス
- 全体解説、選択肢ごとの正誤理由
- 出典ファイル名、PDFビューアー上のページまたはスライド番号、見出し・根拠要約

PDF本文の印刷ページ番号を確実に取得できなかった資料は、「PDFビューアー上のページ」と明記しています。

## 起動方法

静的サイトなのでビルドは不要です。ローカルWebサーバーの公開ディレクトリをこのフォルダーに設定し、`index.html` を開きます。`file://` では問題データを取得できないブラウザーがあるため、HTTPサーバー経由で利用してください。

## 構成

- `index.html`: 画面構造
- `styles.css`: レスポンシブデザイン
- `app.js`: 出題、採点、履歴、リセット、復元
- `questions.json`: 全1,000問と出典情報
- `tests/validate_questions.py`: 問題データの整合性検査

## 注意事項

- 出題予想頻度は資料量、講座での基礎性、複数分野への関連性を基にした非公式の目安です。
- 問題文は、それ自体で解答条件が分かるように整え、「資料の記述と一致するもの」のような出典依存の問い方を使用していません。
- 断片的だった420問は、関連する2つの基礎テーマを独立して問う形式へ再構成しています。
- 資料間に矛盾があると判断した記述は自動的に採用せず、確認可能な記述を優先しています。
- 元資料の改訂により、内容や試験形式が変わる可能性があります。
- 初回アクセス画面は静的サイト上の簡易的な閲覧制限です。問題データを機密情報として保護する認証機能ではありません。
