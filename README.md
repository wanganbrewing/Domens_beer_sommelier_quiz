## はっきりしたクイズ効果音（v60）

正解音を高低2音の「ピンポーン」、不正解音を低く長めの「ブー」に変更しました。5問ごとの連続正解はベルを素早く繰り返して鳴らします。倍音を重ねた響きと長めの余韻で、従来の短い電子音より聞き分けやすくしています。合格・学習完了も明るいチャイム、不合格は下降するブザーにしています。音ON/OFF・設定保存・連続正解の数え方・模試中の正誤非表示は維持します。

検査：`node tests/validate_sound.js` と `node tests/validate_sound_waveform.js`。後者は同じ音の定義をPCM波形にして、音量、長さ、クリッピング、音の立ち上がりと終了を検査します。端末ごとの実聴確認ではありません。

## 効果音と音オン・オフ（v59）

- 学習モードの回答時に、完全正解と不正解で異なる短い効果音を鳴らします。学習完了、模試合格、模試不合格にもそれぞれ別の音があります。模試の回答中には正誤音を鳴らしません。
- 学習モードで5・10・15問…と5の倍数の連続正解に達すると、通常の正解音に代えてボーナス音を鳴らします。不正解で0に戻り、再読み込みや次の50問でも連続数を引き継ぎます。学習履歴のリセットで連続数も消去します。模試の回答・採点はこの連続数に含めません。
- ヘッダーの「音 ON / OFF」でいつでも切り替えられます。初期値はONで、OFFにすると再生中の音も止まります。設定はこのブラウザーに保存し、履歴リセットでは消しません。
- 音は端末内で合成し、音声ファイルの取得や外部送信はありません。最初のタップ・キー操作から利用できます。再読み込みで過去の正誤音や学習完了音を鳴らし直しません。
- 背景タブでは鳴らさず、音の遅延再生もしません。ブラウザーの自動再生制限、端末の音量・消音設定によっては鳴らない場合があります。音に非対応でも回答・採点・画面表示は利用できます。
- 学習モードは従来どおり合否なしの学習完了です。模試の50%以上の合格基準、問題・解説・履歴・資料リンクは変更していません。
- 検査：`node tests/validate_sound.js`（音の区別、5問ごとの連続正解、ON/OFF保存、連打、再開、非対応・再生失敗、模試中の情報保護、終了音の重複防止）。

## ドゥーメンス模試モード

学習モードと、全範囲で受ける模試モードを利用できます。

- 分野・頻度・学習履歴の絞り込みを使わず、有効な問題全体から50問を抽出します。
- 原材料、醸造工程、発酵・熟成、スタイル、歴史・文化、官能、オフフレーバー、サービス・保存、品質・法規、ペアリング、総合知識を広く出題します。現データでは全11分野を含みます。
- 正答数1・2・3・4個を各25%を目標に抽出し、不足する区分だけ他へ再配分します。分野配分は本アプリの練習用設定です。
- 制限時間は40分。再読み込みやページを閉じている間も時間は進み、期限後に戻った場合も保存済み回答を自動採点します。途中で回答や問題順は失われません。
- 終了後に「合格／不合格」、点数、分野別成績を表示します。全問題または「要復習・未回答のみ」で、自分の回答、正答、選択肢別解説、出典を確認できます。
- 形式・採点は [2020年Kiesbye公開試験規則](https://kiesbye.at/wp-content/uploads/2020/01/Pr%C3%BCfungsordnung-Diplom_Biersommelier_01_2020.pdf) を参考にしています。日本開催の現行公式基準や資格全体の合格判定を再現するものではありません。模試内の筆記判定です。

## 試験・採点

50問、40分。全問4択の複数選択式で正答数は回答前に明かしません。
正しい選択肢1つにつき1点、誤選択1つにつき1点減点、1問の最低点は0点。
獲得点÷満点が50%以上で合格です。これは非公式の練習設定です。

追加40問の根拠は以下の英語本文です。

- `0830オフフレーバー、テイスティング実習資料2026その１.pdf`
- `0830ビアペアリング2026.pdf`

原資料PDFそのものはリポジトリへ収録していません。公式問題の転載や再現ではなく、Doemensによる承認・監修も受けていません。
資料の相互作用・ペアリング例は講義上の説明として出題し、万人に同じ官能結果を保証するものではありません。

写真の銘柄、撮影者、ライセンス、出典は `beer-photos.json` と各写真のキャプションに記録しています。
実物写真のない収録スタイルには「AI参考イラスト」と明記した教材用画像を表示します。実在銘柄の写真と混同しない表示にしています。画像未登録のスタイルにも既存の代表銘柄・解説・購入リンクを表示します。
画像はグラス全体を見られるよう縦横比を維持し、iPhoneでも横にはみ出さない表示にします。

## 起動・検査

ビルド不要の静的サイトです。このフォルダーで `python -m http.server 8000` を起動してください。

```sh
python tests/validate_questions.py
python tests/validate_english_supplement.py
python tests/validate_doemens_health.py
python tests/validate_question_copy.py
python tests/validate_choice_wording.py
python tests/validate_concrete_distractors.py
python tests/validate_japanese_answers.py
python tests/validate_blind_tasting.py
node tests/validate_sampling.js
node tests/validate_style_sanitizer.js
node tests/validate_style_search_links.js
node tests/validate_style_link_coverage.js
node tests/validate_mock_exam.js
node tests/validate_beer_images.js
node tests/validate_home_cleanup.js
node tests/validate_health_feedback.js
node tests/validate_choice_variants.js
node tests/validate_study_continuation.js
node tests/validate_recent_accuracy.js
python tests/validate_source_links.py
node tests/validate_source_viewer.js
node tests/validate_drive_sources.js
node tools/check_drive_source_links.js
```

問題追加データの再生成：`python tools/add_2026_handouts.py` の後に `python tools/add_english_course_supplement.py`。各追加IDを置き換えるため再実行しても重複しません。後者は英語資料の補強とOF26-007の表現訂正を適用し、`tools/add_doemens_health_supplement.py` を続けて実行します。生成時には `data/choice-wording-revisions.json` の確認済み修正と `data/japanese-answer-text.json` の日本語併記も適用します。文言修正だけを再適用する場合は `python tools/apply_reviewed_choice_wording.py`。健康資料の追加12問だけを更新する場合は `python tools/add_doemens_health_supplement.py`。既存IDと順番を保ち、どちらの経路でも重複しません。

## 保存と閲覧制限

学習履歴・設定はブラウザーのローカルストレージに保存します。外部へ送信しません。
簡易パスワード画面とnoindex指定は、公開リポジトリの情報を非公開にする認証機能ではありません。
販売ページの在庫・価格・条件は変わるため各ページで確認してください。
